Kebijakan privasi OmniCloud Local

Diperbarui: 25 Oktober 2026

Kebijakan ini menjelaskan instalasi pribadi OmniCloud yang dikelola Fajar Zikri Utama pada perangkat miliknya. Instalasi ini tidak menawarkan akun atau layanan penyimpanan publik.

Data yang diakses

Dengan izin pemilik akun, aplikasi mengakses identitas dasar akun Google, alamat email, kuota penyimpanan, serta metadata file dan folder seperti nama, ukuran, jenis, dan waktu perubahan. Isi file diproses ketika diperlukan untuk operasi seperti pratinjau, unduhan, atau unggahan.

Penggunaan data

Data dipakai untuk menampilkan dan menyinkronkan daftar file, menampilkan kuota, dan menjalankan operasi file yang tersedia dalam aplikasi. Izin Google Drive yang diminta mencakup membaca dan mengelola file, termasuk membuat, mengubah, dan menghapusnya.

Penyimpanan dan koneksi

Metadata dan konfigurasi akun disimpan dalam database SQLite lokal. Kredensial akun dan token OAuth disimpan terenkripsi oleh aplikasi. Berkas konfigurasi lokal juga berisi client secret OAuth. Log diagnosis dapat disimpan secara lokal untuk penanganan kesalahan.

Aplikasi menghubungi layanan Google untuk otorisasi dan operasi Google Drive. Token akses diperbarui melalui layanan OAuth Google selama izin masih berlaku. Penggunaan layanan Google juga tunduk pada kebijakan Google.

Kontrol dan penghapusan

Pemilik dapat memutus koneksi akun melalui aplikasi dan mencabut izin OmniCloud Local melalui pengaturan koneksi pihak ketiga Akun Google. Berkas database, konfigurasi, log, dan salinan cadangan lokal tetap berada pada perangkat atau media backup sampai dihapus oleh pemilik.

Penghapusan berkas lokal dan pencabutan akses OAuth tidak sama dengan menghapus file yang tersimpan di Google Drive.

Cakupan

Kebijakan ini khusus untuk instalasi pribadi tersebut. Kebijakan dan praktik layanan cloud yang dihubungkan berlaku secara terpisah. Informasi pemilik tersedia pada website Fajar Zikri Utama.
